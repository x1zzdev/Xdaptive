# Trademark policy

The Apache-2.0 license covers the **code and the specification** in this
repository. It does not grant rights to the project's names or marks.

## Marks

- **Xdaptive** — the project name.
- **Xdaptive OS** — the product name.
- **Adaptive Computing OS** — the category descriptor.
- **Beyond Applications.** — the project slogan.

The name "Xdaptive" is reserved for the canonical project. Report any
confusingly similar use in an issue.

## What you may do without asking

- Use the marks to refer to this project, its specification, or its releases
  (nominative use): "built on Xdaptive", "compatible with the Xdaptive AIR".
- Redistribute unmodified releases under the Apache-2.0 terms.
- State that your work implements or targets the specification.

## What needs permission

- Using a mark in a product, company, or domain name in a way that suggests it
  is the official Xdaptive project or is endorsed by it.
- Distributing a modified build under the name "Xdaptive OS" without making the
  modification clear.
- Using the marks in a logo or branding that could be confused with the
  project's own.

## Forks

A fork is welcome under the license. A fork that changes behaviour should use a
distinct name and must not imply it is the upstream project. Say plainly which
commit it is based on.
