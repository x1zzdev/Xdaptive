# Troubleshooting

Problems hit while building Xdaptive, and how they were resolved.

This is not a bug tracker (that is GitHub Issues). It records the *reasoning* of
a fix when the reason does not belong in the code or the specification: an
environment quirk, a wrong assumption, a decision that turned out to be
unworkable.

## Format

```text
## <short title>  (YYYY-MM-DD)

**Symptom.** What was observed.
**Cause.** Why it happened, once known.
**Fix / decision.** What was done, and why.
**Follow-up.** What is still open, if anything.
```
